## 0. 공통 규칙

- **패치**: 1.08 이후 밸런스 변경 없음(1.16.1·리마스터 동일). 모든 카드의 `patch = "1.08+"`.
- **시간**: 리마스터 게임 시계 기준 근사치(≈). **1차 기준은 서플라이·이벤트**(예: "레어 완료 시")이며, 시간은 리플레이로 보정한다.
- **서플 표기**: `12 해처리` = 인구 12에서 해처리 건설.
- **단계**: 초반(≈0~5분) / 중반(≈5~12분) / 후반(≈12분~).
- **분류**: 빌드 / 운영 / 전투 / 정찰 / 대응.
- **출처**: "수집 필요"는 리플레이·VOD로 채울 슬롯이다. 선수 이름은 널리 알려진 연관만 적었고, 나머지는 "프로 정석"으로 표기했다.

## 0.2 분기 표기 문법 (변환기 파싱용)

`- 조건 → 행동1, 행동2`

- **조건 어휘**: `적 X 확인`, `적 X N+`, `시간 < T`, `아군 X N+`, `정찰 실패`, `X 손실`
- **행동 어휘**: 생산 / 건설 / 연구 / 취소 / 드론 중단·재개 / 일꾼 동원 / 정찰 / 공격(대상) / 수비(위치) / 확장 / 후퇴 / 우선순위↑↓ / 전환(체제) / 카드 이동(ID)

# Nova-Z · ZvT (13)

### Z-ZvT-01 · 3해처리 뮤탈 (표준)
`Z vs T · 초반→중반 · 빌드`
- **목표**: 앞마당과 3번째 해처리 경제를 먼저 깐다. 뮤탈 10기 이상을 한 번에 띄워 테란을 수비에 묶고, 그동안 드론과 확장에서 앞서 간다.
- **전제**: 정찰로 BBS·8배럭이 아님을 확인했고, 앞마당이 안정적이다.
- **진행**:
  1. 9 오버로드 → 12 앞마당 해처리 → 11 스포닝 풀 → 10 익스트랙터
  2. 풀이 완료되면 저글링 1~2쌍을 뽑는다(SCV 정찰 차단, 입구 감시). 드론은 계속 생산한다.
  3. 13~14 무렵 3번째 해처리를 짓는다(3번째 지역 또는 본진 매크로).
  4. 가스 100 → 레어. 다음 가스 100으로 저글링 발업(순서는 변형이 많음).
  5. 레어 완료 → 스파이어, 앞마당 가스 추가
  6. 스파이어 완성 직전 라바와 자원을 비축했다가 뮤탈을 동시 생산한다(10~12기).
- **분기**:
  - 적 CC 퍼스트/1배럭 더블 확인 → 드론 우선순위↑, 3번째 해처리 앞당김
  - 적 2배럭 아카데미(메딕 조기) 확인 → 앞마당 성큰 1~2, 저글링 추가, 카드 이동(Z-ZvT-08)
  - 적 팩토리·탱크 조기 확인 → 지상 정면 공격 금지, 뮤탈 본진 견제 우선순위↑
  - 적 본진 터렛 3+ 확인 → 뮤탈은 멀티·이동 병력 견제로 돌리고 카드 이동(Z-ZvT-09)
  - 적 발키리 확인 → 뮤탈 생산 중단, 스커지·지상 체제로 전환
- **규칙**: 뮤탈은 한 덩어리로만 움직이고 터렛 사거리에는 들어가지 않는다. 체력이 빠진 뮤탈은 빼서 재생시킨다.
- **실패**: 뮤탈을 쪼개 쓰다 소모한다. 뮤탈을 띄운 뒤 드론이 정체된다. +1 바이오닉이 진출할 때 성큰·러커가 부족하다.
- **팁**: 뮤탈의 가치는 '살아 있는 수'다. 테란 병력이 견제에 묶인 시간이 곧 저그 드론 시간이다.
- **상대 카드**: T-TvZ-01, 02, 03, 08
- **출처/맵**: 후기 KeSPA~ASL ZvT 정석, 리플레이 수집 필요 · #표준맵

### Z-ZvT-02 · 2해처리 뮤탈 (공격형)
`Z vs T · 초반→중반 · 빌드`
- **목표**: 터렛과 메딕이 갖춰지기 전에 뮤탈을 띄워 SCV와 마린에게 피해를 누적시킨다.
- **전제**: 테란이 CC 퍼스트처럼 바이오닉이 늦은 오프닝을 썼음을 확인했다.
- **진행**:
  1. 9 오버로드 → 12 해처리 → 11 풀 → 10 가스
  2. 가스 100 → 레어, 이후 스파이어를 짓는다. 3번째 해처리는 생략하거나 늦춘다.
  3. 뮤탈 6~9기로 본진 미네랄 라인을 타격한다.
  4. 견제를 마치면 3번째 해처리를 짓고 드론을 회복한다.
- **분기**:
  - 적 터렛 2+ 이미 완성 → 뮤탈 수 축소, 3해처리·드론 회복
  - 적 마린 대량+메딕 확인 → 견제는 짧게 끝내고 러커 준비
  - 적 앞마당 수비 약함 확인 → 저글링을 동반해 앞마당 동시 압박
- **실패**: 경제가 얇아서 장기전에서 불리해진다. 뮤탈을 잃으면 만회할 수 없다.
- **상대 카드**: T-TvZ-02, 08
- **출처/맵**: 프로 정석(수집 필요) · #러시거리_짧음 유리

### Z-ZvT-03 · 9오버풀 저글링 압박 → 앞마당
`Z vs T · 초반 · 빌드`
- **목표**: CC 퍼스트·노배럭 테란에게 SCV 피해를 주거나 CC 지연을 유도한 뒤, 정상 운영으로 합류한다.
- **진행**:
  1. 9 오버로드 → 9 풀(오버풀) → 11 앞마당 해처리
  2. 저글링 2~3쌍을 즉시 상대 앞마당으로 보낸다.
  3. (선택) 가스 → 발업
- **분기**:
  - 벙커 완성 전 도착 → 벙커 건설 SCV 우선 공격
  - 벙커 완성 확인 → 공격 중지, 저글링은 정찰 위치로 보내고 드론 재개
  - 적 CC 퍼스트 확인 → 압박 강도↑, 미네랄 라인 SCV 공격
  - 적 1배럭(마린 선) 확인 → 시간만 벌고 회군
- **실패**: 벙커와 SCV 수리에 저글링이 녹는다. 이 경우 3해처리 대비 경제 손해가 남는다.
- **상대 카드**: T-TvZ-02(유리), T-TvZ-19
- **출처/맵**: 프로 정석 · #러시거리_짧음

### Z-ZvT-04 · 4풀/5풀 저글링 올인
`Z vs T · 초반 · 빌드`
- **목표**: 첫 배럭·벙커가 서기 전에 SCV를 대량 처치한다.
- **진행**: 4(또는 5) 풀 → 저글링 연속 생산 → 드론 6~7 유지, 저글링은 본진으로 직행한다.
- **분기**:
  - 적 SCV 대량 동원 → 일꾼 정면 교전 피하고 외곽 SCV 끊어먹기
  - 적 배럭+서플 심시티 확인 → 성공률 급락, 피해 계산 후 드론 재건 판단
  - SCV 6+ 처치 → 저글링 계속 생산(올인 지속)
- **실패**: 4인맵에서 정찰이 실패해 이동 시간을 잃는다. 입구 벽에 막힌다.
- **메모**: 승률보다 **스파링 다양성** 목적이다. Nova-TvZ가 치즈 대응을 배우게 한다.
- **상대 카드**: T-TvZ-20

### Z-ZvT-05 · 정찰: 테란 오프닝 판독
`Z vs T · 초반 · 정찰`
- **목표**: 3분 이내에 테란 오프닝을 {CC퍼스트, 1배럭더블, 2배럭아카데미, BBS/8배럭, 팩토리(메카닉), 2스타} 중 하나로 분류한다.
- **진행**:
  1. 첫 오버로드는 예상 상대 본진, 두 번째는 앞마당 상공으로 보낸다.
  2. 드론 정찰(4인맵 9~12)로 배럭 수, 가스 유무, CC 위치 세 가지만 확인하고 복귀한다.
  3. 저글링 1쌍으로 앞마당과 진출로를 상시 감시한다.
- **판독 단서**:
  - 배럭 0 + 앞마당 CC → CC 퍼스트
  - 배럭 1 + 앞마당 CC → 1배럭 더블
  - 배럭 2 + 아카데미/가스, 앞마당 지연 → 2배럭 아카데미
  - 본진 배럭 없음 + 일꾼 수 적음 → 전진 배럭(BBS) 의심
  - 가스 조기 + 팩토리 → 메카닉/벌처
  - 스타포트 2 → 레이스
- **분기**:
  - 정찰 실패 & 시간 < 2:30 → 오버로드 희생을 감수하고 추가 정찰
  - BBS 의심 → 카드 이동(Z-ZvT-06)
- **규칙**: 오버로드는 마린 사거리 밖에 둔다(레어 전에는 속업이 없다).
- **상대 카드**: T-TvZ-09

### Z-ZvT-06 · vs BBS / 8배럭 벙커링 수비
`Z vs T · 초반 · 대응`
- **목표**: 일꾼 손실을 최소화하고 벙커를 완성 전에 차단한다.
- **진행**:
  1. 단서를 잡으면 저글링 생산을 최우선한다.
  2. 벙커 건설 SCV를 발견하면 드론 4~6기를 동원해 건설 SCV를 공격한다.
  3. 벙커가 완성되면 앞마당 해처리 취소를 검토한다(취소 시 75% 환급).
  4. 성큰과 저글링을 확보한 뒤 수리 SCV를 끊는다.
- **분기**:
  - 벙커가 앞마당 해처리를 겨냥 → 해처리 취소, 본진 1해처리로 성큰+저글링
  - 적 마린 3 미만 & 아군 저글링 4+ → 반격, 전진 배럭 위치 정찰
  - 수비 성공 → 테란 손해가 크므로 드론 정상화, 2해처리 뮤탈로 응징(Z-ZvT-02)
- **실패**: 해처리를 고집하다 일꾼과 라바를 모두 잃는다.
- **상대 카드**: T-TvZ-04

### Z-ZvT-07 · 뮤탈 견제 운영 (뭉치기·우선 타겟)
`Z vs T · 중반 · 전투`
- **목표**: 뮤탈을 잃지 않으면서 SCV, 메딕, 고립된 탱크를 제거하고 테란 병력을 분산·고정시킨다.
- **진행**:
  1. 첫 비행은 터렛이 없는 지점부터 간다(본진 미네랄 뒤 → 앞마당 → 이동 병력).
  2. 마린이 모이기 전에 몇 초 동안 치고 빠진다.
  3. 우선 타겟: 터렛 건설 SCV > 미네랄 SCV > 메딕 > 지원 없는 탱크 > 마린
  4. 체력 50% 이하인 뮤탈은 분리해서 재생시킨다.
- **분기**:
  - 적 사이언스 베슬 확인 → 뮤탈 즉시 산개, 스커지로 베슬 사냥(Z-ZvT-10)
  - 적 발키리 확인 → 교전 회피
  - 적 본대 진출 → 뮤탈로 본진을 쳐서 회군 강요, 저글링으로 진출 병력 지연
- **규칙**: 스팀 마린+메딕 8기 이상과는 정면 교전하지 않는다. 터렛 두 개 사이로 진입하지 않는다.
- **실패**: 도망가는 마린을 끝까지 쫓다가 본대에 녹는다.
- **팁**: 뭉치기 컨트롤(이제동 등이 대표적)로 쿠션 효과를 낸다. 뭉치면 스플래시 손해와 마린 집중 사격 손해가 줄어든다.
- **상대 카드**: T-TvZ-07, 08, 11

### Z-ZvT-08 · vs 바이오닉 +1 타이밍 수비
`Z vs T · 중반 · 대응`
- **목표**: 메딕·스팀·+1 마린 진출을 성큰, 러커, 저글링 서라운드로 막아 테란 타이밍을 무력화한다.
- **진행**:
  1. 2배럭 아카데미나 +1 엔베를 확인하면 앞마당과 3번째에 성큰 2~3을 짓는다.
  2. 히드라덴 → 러커 연구(뮤탈과 병행하거나 뮤탈을 대체)
  3. 러커 2~4기를 진출로 길목에 매복시키고, 저글링은 측면에 대기시킨다.
  4. 테란이 러커 앞에서 멈추는 순간 저글링으로 후방을 서라운드하고, 뮤탈은 메딕을 노린다.
- **분기**:
  - 적 베슬 동반 → 러커 수비선 후퇴, 스커지 우선순위↑
  - 적 탱크 동반 → 시즈 위치를 저글링으로 직접 타격
  - 적 우회 드랍 → 저글링 일부만 회군, 본대 유지
- **실패**: 성큰만 늘려 경제를 잃는다. 디텍된 러커로 메딕+마린과 정면 교전한다.
- **상대 카드**: T-TvZ-03, 06

### Z-ZvT-09 · 뮤탈 이후 저글링·러커 중반 운영
`Z vs T · 중반 · 운영`
- **목표**: 4가스 운영을 기반으로 러커 진지와 저글링 기동으로 맵을 장악하며 하이브에 도달한다.
- **진행**:
  1. 뮤탈 견제가 끝나면 히드라덴 → 러커
  2. 3·4번째 가스를 확보하고 에볼루션 챔버 지상 업그레이드를 시작한다.
  3. 러커는 2~3기 단위로 테란 진출로 길목에 분산 매복시킨다.
  4. 퀸즈 네스트 → 하이브 → 디파일러 마운드
- **분기**:
